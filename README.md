# Nokoribi-bot

基于 [@fraqjs/fraq](https://github.com/fraqjs/fraq) 框架的 QQ Bot 程序，适配 Milky Protocol。

为 Nokoribi Bot 提供支持。

## 依赖

- Node.js 24
- pnpm 11.3.0
- 支持 Milky 1.3 协议的任意协议端

## 命令

- 安装依赖：

```bash
pnpm install
```

- 构建：

```bash
pnpm build
```

- 运行：

```bash
pnpm start
```

- 开发环境：

```bash
pnpm dev
```
